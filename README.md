# WhatsApp Sandbox

A responsive, two-sided WhatsApp conversation and Flow simulator built with Next.js, React, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- Customer and Business/Admin phone previews sharing one message state.
- WhatsApp-inspired chat bubbles, timestamps, blue read receipts, phone bezels, dynamic island, and patterned chat background.
- Animated bottom-sheet appointment Flow with service, date, and time fields.
- Structured booking submission appears in the customer chat and as an active-flow summary in the business chat.
- Mock Integration Triggered panel shows the latest event payload and endpoint.
- Send messages from either side, reset the demo, and export the conversation as JSON.
- Responsive layout for desktop and mobile.

## Run locally

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

This is a front-end simulation. It does not connect to WhatsApp, call a real backend, or create real appointments. The integration panel displays mock event payloads locally in the browser.

## Publish to the target GitHub repository

The source is intended for `https://github.com/TheoTime01/WhatsApp-Sandbox`. To publish it from a machine where you have GitHub write access:

1. Download and extract this project.
2. Clone the repository and copy the extracted project files into that clone (keep its `.git` directory):

   ```bash
   git clone https://github.com/TheoTime01/WhatsApp-Sandbox.git
   cd WhatsApp-Sandbox
   # Copy the extracted project files into this directory.
   npm install
   npm run dev
   git add app package.json package-lock.json postcss.config.mjs tsconfig.json next-env.d.ts .gitignore README.md
   git commit -m "Build WhatsApp Sandbox simulator"
   git push origin main
   ```

   If `package-lock.json` was not generated by `npm install`, omit it from `git add`.

The ChatGPT GitHub integration available during this build returned `403 Resource not accessible by integration` for write operations, so these files have **not** been committed to GitHub by this session.
