# WhatsApp Sandbox

A responsive, three-phone WhatsApp conversation and Flow simulator built with Next.js, React, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- Sender, Traveler and Receiver phone previews sharing one group-chat message state.
- WhatsApp-inspired chat bubbles, timestamps, blue read receipts, phone bezels, dynamic island, and patterned chat background.
- Animated bottom-sheet delivery-request Flow with service, date, and time fields.
- Structured delivery request from the Sender appears in the shared chat and as an active-flow summary on the Traveler and Receiver phones.
- Mock Integration Triggered panel shows the latest event payload and endpoint.
- Send messages from any phone, reset the demo, and export the conversation as JSON.
- Responsive layout for desktop and mobile.

## WhatsApp Flows support

Modelled on the examples in [WhatsApp/WhatsApp-Flows-Tools](https://github.com/WhatsApp/WhatsApp-Flows-Tools) (Flow JSON, endpoint contract, Flow API and Cloud API payloads).

- **Flow JSON runtime** rendered inside each phone: screens with `SingleColumnLayout`, `Form`, `TextHeading/Subheading/Body/Caption`, `TextInput` (text, number, email, phone, password), `TextArea`, `Dropdown`, `RadioButtonsGroup`, `CheckboxGroup`, `DatePicker`, `OptIn`, `EmbeddedLink`, `Image` and `Footer`.
- **Actions**: `navigate`, `data_exchange`, `complete`, plus `on-select-action`, `${form.x}` / `${data.x}` / `${screen.ID.form.x}` references, `visible` / `enabled`, dynamic `data-source`, required-field and input validation, back navigation, terminal screens.
- **Mock endpoint** (version 3.0): `ping`, `INIT`, `data_exchange`, `BACK`, error notifications, `flow_token`, `extension_message_response`. Toggle it offline to see client error handling.
- **Flow Studio**: create, edit (validated JSON), save, publish, deprecate, duplicate and delete flows (DRAFT / PUBLISHED / DEPRECATED), send flow messages (header, body, footer, `flow_cta`, draft/published mode, `navigate` or `data_exchange` start) with the Cloud API payload shown, endpoint request log and metrics.
- Completing a Flow posts the response into the chat and logs the `nfm_reply` webhook payload.

Not implemented: real AES/RSA payload encryption, newer components (e.g. NavigationList, CalendarPicker, PhotoPicker, ChipsSelector rendering), `If`/`Switch` rendering, templates with Flow buttons, and real Graph API calls.

## Run locally

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

This is a front-end simulation. It does not connect to WhatsApp, call a real backend, or create real appointments. The integration panel displays mock event payloads locally in the browser.

## Publish to the target GitHub repository

The source is intended for `https://github.com/TheoTime01/WhatsApp-Sandbox`. To publish it from a machine where you have GitHub write access:

1. Download and extract this project.
2. Clone the repository and copy the extracted project files into that clone (keep its `.git` directory):

   ```bash
   git clone https://github.com/TheoTime01/WhatsApp-Sandbox.git
   cd WhatsApp-Sandbox
   # Copy the extracted project files into this directory.
   npm install
   npm run dev
   git add app package.json package-lock.json postcss.config.mjs tsconfig.json next-env.d.ts .gitignore README.md
   git commit -m "Build WhatsApp Sandbox simulator"
   git push origin main
   ```

   If `package-lock.json` was not generated by `npm install`, omit it from `git add`.

The ChatGPT GitHub integration available during this build returned `403 Resource not accessible by integration` for write operations, so these files have **not** been committed to GitHub by this session.
